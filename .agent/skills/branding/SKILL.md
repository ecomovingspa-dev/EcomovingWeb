# 🛡️ Skill: Branding & Corporate Identity

Este skill actúa como la **Biblia Identitaria** de Ecomoving SpA. Su objetivo es garantizar la coherencia absoluta entre el Hub de Gestión (La Fábrica) y los productos editoriales generados (Tiny Puertecillo, Ecomoving Site).

---

## 1. Núcleo Corporativo: Ecomoving SpA

### Filosofía de Marca
Ecomoving no vende contenedores; vende **Arquitectura Modular de Alto Desempeño**. La marca debe sentirse como una mezcla entre **Tesla** (tecnología/sustentabilidad) y **Architectural Digest** (lujo/estética).

### ADN Visual (Ecomoving Master)
*   **Creative North Star**: "Industrial High-Tech Luxury".
*   **Colores Primarios**: 
    *   Negro Absoluto (#000000 / #050505)
    *   Turquesa Ecomoving (#00d4bd) - *Uso acentuado para botones y estados activos.*
*   **Tipografía**: **Inter** (Variable). Estilo minimalista, limpio y moderno. 
*   **Iconografía**: Lucide Icons (Stroke 1.5 - 2px). Siempre minimalista y funcional.

---

## 2. Línea Editorial: Tiny Puertecillo SpA

### Filosofía de Marca
Un refugio arquitectónico premium. Menos "aplicación móvil", más "revista de diseño boutique".

### ADN Visual (Organic Brutalism)
*   **Creative North Star**: "The Coastal Curator".
*   **Colores Primarios**: 
    *   Base Arena (`surface` #fff9ef)
    *   Sombras de Bosque (`primary` #001f14)
    *   Tierra Oxidada (`secondary` #964828)
*   **Tipografía**: 
    *   **Noto Serif**: Para titulares y narrativa (Lujo editorial).
    *   **Manrope**: Para cuerpo de texto y etiquetas (Elegancia funcional).
*   **Regla de Oro**: *"Tonal Carving"*. No usar líneas de 1px para separar secciones; usar cambios sutiles de color de fondo.

---

## 3. Tono de Voz y Narrativa (Protocolo ADN)

Todo texto generado bajo este skill debe seguir estas reglas:
1.  **Autoridad Serena**: Evitar exclamaciones excesivas. El lujo no grita; se impone por su presencia.
2.  **Sustentabilidad Técnica**: No usar el término "Eco-friendly" de forma genérica. Usar "Sustentabilidad Estructural" o "Eficiencia Modular".
3.  **Enfoque B2B**: Hablar de "Retorno de inversión", "Activo Arquitectónico" y "Escalabilidad".

---

## 4. Gestión de Proyectos en "La Fábrica"

Cuando este skill esté activo, el Hub debe:
*   Identificar en qué carpeta de proyecto está trabajando.
*   **Cargar automáticamente los tokens de diseño** (colores y tipografías) correspondientes a dicha marca para evitar mezclas visuales incoherentes.
